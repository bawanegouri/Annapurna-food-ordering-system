# Annapurna - Online Food Ordering System

## Description
Annapurna is an online vegetarian food ordering system developed using Node.js, Express.js, HTML, CSS, JavaScript, and Bootstrap.

## Features

### Customer
- Register & Login
- Browse Menu
- Search Food
- Add to Cart
- Checkout
- Order History
- Logout

### Admin
- Admin Dashboard
- Add Food
- Manage Food
- Delete Food
- View Orders
- Update Order Status

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Node.js
- Express.js
- JSON

## Installation

```bash
npm install
node server.js
```

Open:

```
http://localhost:3000
```
